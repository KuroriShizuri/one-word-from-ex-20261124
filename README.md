One word, 10 characters: the honest, slightly exhausted summary of dating someone who never, ever stops.

> Relentless

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it (1–24 characters, UTF-8, exactly one word — stricter than the kit gate, which requires only 1–24 non-whitespace UTF-8 characters), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
